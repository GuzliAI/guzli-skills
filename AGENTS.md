# Guzli skills repository

This repo publishes portable [Agent Skills](https://agentskills.io) for Guzli MCP.

- Skill packages live under `skills/<name>/SKILL.md`.
- Read [INSTALL.md](INSTALL.md) before copying skills into Claude, Codex, Cursor, OpenClaw, Muse, Grok, or other hosts.
- Guzli MCP endpoint: `https://mcp.guzli.com/mcp` (OAuth via `https://gateway.guzli.com`).
- Do not commit customer lists, API tokens, or private org goals into skill files.
